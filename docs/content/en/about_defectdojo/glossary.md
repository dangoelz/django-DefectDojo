Below is a simple glossary of useful terms to help understand DefectDojo's various functions. 

| Term     | Definition                                                        |
| -------- | ----------------------------------------------------------------- |
| GTM      | Go to market                                                      |
| AppSec   | Application Security                                              |
| CISO     | Chief Information Security Officer                                |
| BISO     | Business Information Security Officers                            |
| OWASP    | Organization of Working App Sec Professionals                     |
| OSS      | Open-Source Software                                              |
| CI/CD    | Continuous Integration, Continuous Delivery                       |
| IaC      | Infrastructure as Code                                            |
| API      | Application Programming Interface                                 |
| SDLC     | System Developoment Lifecycle                                     |
| SaaS     | Software as a Service                                             |
| DaaS     | Data as a Service                                                 |
| PR       | Pull Request                                                      |
| SAMM     | Sofware Assurance Maturity Model                                  |
| SAST     | Static Application Security Testing                               |
| DAST     | Dynamic Application Security Testing                              |
| IAST     | Interactive Application Security Testing                          |
| XXS      | Cross-Site Scripting                                              |
| WAF      | Web Application Firewall                                          |
| RASP     | Runtime Application Self-Protection                               |
| RBAC     | Role-Based Access Control                                         |
| ABAC     | Attribute-Based Access Control                                    |
| SCA      | Software Composition Analysis                                     |
| TLS      | Transport Layer Security                                          |
| mTLS     | Mutual Transport Layer Security                                   |
| CLI      | Command Line Interface                                            |
| CVE      | Common Vulnerabilities and Exposures                              |
| REST API | Representational State Transfer Application Programming Interface |
| SCM      | Source Code Management                                            |
| VEPs     | Vendor-Equivalent Products                                        |
| EPSS     | Exploit Prediction Scoring System                                 |
| CWE      | Common Weakness Enumeration                                       |
